# Rafla Design website
Static site (no build step needed to deploy). Cloudflare Pages: framework preset "None", build command empty, output directory "/".

Edit content in `build.py`, run `python3 build.py` (set `WEB3FORMS_KEY=...` to switch on the enquiry form), commit, push.
Projects: add a webp to `images/` and a card in `page_portfolio()`.
